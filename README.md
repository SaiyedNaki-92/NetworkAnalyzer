Real-Time Network Traffic Analyzer built with Python, Scapy, Tkinter, and Matplotlib for live packet capture, protocol analysis, and graphical network traffic visualization.
# Real-Time Network Traffic Analyzer

A Python-based network monitoring application that captures and analyzes live network traffic in real time.

## Features

* Real-time packet capture
* TCP, UDP, ICMP protocol analysis
* Live graphical dashboard
* Traffic visualization using Matplotlib
* Multi-threaded packet processing

## Technologies Used

* Python
* Scapy
* Tkinter
* Matplotlib

## Project Structure

NetworkAnalyzer/
├── main.py
├── packet_capture.py
├── gui.py
└── requirements.txt

## Installation

Install the required libraries:

python -m pip install scapy matplotlib

## Run the Project

python main.py

## Objective

This project demonstrates network packet analysis, protocol monitoring, GUI development, and real-time data visualization using Python.
